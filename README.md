# 毎日リアル英語

英語初心者向けの英会話学習アプリ。ネイティブの日常会話・スラング・ドラマ・ニュースの決まり文句を、1日15分で学ぶ。

- 会話シーン26・表現130（はじめの一歩／友だち・恋愛／職場／ドラマ／ニュース）
- 間隔反復（FSRS）、想起練習、イラスト＋絵文字の手がかり
- 会話・表現・単語はニューラル音声（Kokoro）で読み上げ。単語は1語ずつタップで再生
- AIの例文・会話の返事も、スマホの中で Kokoro（kokoro-js、Apache-2.0）を動かして同じAI音声で読む（初回に音声データを Hugging Face から読み込み）
- 🎤で話してシャドーイング判定、録音してネイティブと聞き比べ
- AI（Claude API）と声で会話。発音のずれと不自然な言い方を直す

## 使い方

GitHub Pages で公開したページを Android の Chrome で開く。AI機能は、設定画面に自分の Anthropic APIキーを入れると使える（キーはその端末のブラウザにだけ保存され、このリポジトリには含まれない）。
